# Portfolio

Manideep Thumu's portfolio. Astro, plain CSS, vanilla TypeScript. Served at https://manideep-2007-ok.github.io/Portfolio/.

The design and content rules are in `CLAUDE.md`, `BRIEF.md` and `DESIGN.md`. The site is being rebuilt in phases.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build into dist/
npm run shots    # screenshots into .shots/
npm run a11y     # axe accessibility audit
npm run check    # content and source rules
```
